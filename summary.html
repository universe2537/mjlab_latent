SONIC Encoder Integration

  • Local checkpoint link: ckpt/GEAR-SONIC points to /data0/universe/ckpt/GEAR-SONIC.
  • SONIC decoder ONNX input is 994 = 64 token + 10 * (6 + 3 * 29). The existing action term feeds token, angular velocity history, joint position/velocity history, last action history, and gravity history.
  • SONIC encoder ONNX input is 1762 and output is 64. For the G1 encoder mode, the useful slices are mode one-hot, 10-frame joint position history, 10-frame joint velocity history, and 10-frame anchor orientation history.
  • The exported encoder had fixed-batch Reshape constants such as [1, 1, 10, 6]. The action term now patches Reshape shape constants whose first dimension is fixed to 1, replacing it with -1 so vectorized env batches work.
  • The encoder-prior token currently uses: token = encoder(current_proprio_history) + 0.2 * tanh(policy_action), followed by the configured token clip.
