主线判断

如果目标是完整接网球 demo，短期应以原始 Cross 能力为基线，先把连续接球的 recovery/respawn 做稳；不要过早把 SONIC encoder-prior 作为主线。

LAB 的价值在“动作更稳定”，但目前牺牲了回球成功率。后续要靠更强 post-hit/landing 信号或更精细 action parameterization，而不是单纯多跑 iter。

关键风险

Cross 系列的 Policy/mean_std 普遍异常高，说明探索噪声或 checkpoint 继承状态仍会污染后续任务。

连续任务目前有回球信号，但 continuous_rally_complete 仍为 0；它还不是多回合 demo。

实验族谱

  1. Tracking / Distillation：提供 G1-with-racket 的运动先验和 frozen latent decoder。关键 decoder ckpt 是 logs/rsl_rl/g1_distillation/distill_cloud_unitree_racket_tennis_2026-05-12_09-35-14/model_30000.pt。
  2. Latent Hit：学习第一次球拍接触，为 Cross 提供 resume checkpoint。
  3. Latent Cross：从 Hit 继续，学习击球后过网和对方半场落点，是当前最佳性能基线。
  4. Clamp std：算法稳定性尝试，结论是直接 clamp std 会破坏已学会的 Cross 策略。
  5. LAB / Wrist-LAB：尝试把高层动作限制在合理流形附近，视觉更稳但 Cross 正确率下降。
  6. Continuous：把单次 Cross 扩展为多球回合，最新版本加入 recovery phase、respawn countdown 和 rally-length curriculum。
  7. SONIC：复用 SONIC decoder/encoder；direct token 在 Hit 上可学，encoder prior 初版在当前输入构造下不稳。

推荐下一步

  1. Continuous 主线继续看恢复期：当前 active run 已经有 recovery reward，但 rally complete 仍为 0。先生成视频，确认是恢复站姿失败、第二球来球时机不合理，还是击球后动作无法回正。
  2. Cross baseline 做稳定版：不要再直接 clamp std。更好的做法是降低 entropy、重置/约束 std 初始化、或者在 resume 时显式处理 distribution 状态。
  3. LAB 只作为稳定性分支：从 Cross 继续优于从 Hit-LAB 继续。需要提高 post-hit/cross/landing 的相对权重，减少只挡球的局部最优。
  4. SONIC encoder prior 暂停转 Cross：Hit encoder-prior root_height 崩溃，说明当前 encoder 输入构造或 token prior 不适合直接训练。先离线对比 encoder token 解码动作是否站得住，再进入 RL。
  5. 统一实验记录：后续每个新 run 至少记录：起点 checkpoint、关键改动、预期变化指标、最后指标、视频路径。

指标解释
  • Train/mean_reward：每轮 rollout 的平均 reward，跨任务不可直接比较，只能看同任务趋势。
  • Policy/mean_std：Gaussian policy 的探索标准差。Cross 中数百到上千代表动作分布很吵，即使 reward 高也可能不稳定。
  • racket_hit_event / first_racket_hit：是否能完成首次有效球拍接触，Hit 任务核心指标。
  • post_hit_x_progress / post_hit_ball_velocity_direction：击球后球是否朝对方半场推进，是 Cross 的中间质量指标。
  • crossed_net_event：球过网事件；为 0 时通常是挡球、粘球、球速方向不对。
  • landing_in_bounds_event / landing_in_bounds_after_hit：真正的 Cross 成功信号，表示击球后对方半场界内落地。
  • second_contact：二次接触高通常表示挡球/黏球局部最优。
  • root_height / bad_orientation：身体稳定性问题，过高说明动作先验或控制输出破坏站立。
  • ball_out_of_bounds：球离场，可能是没击中、击球方向差，或回球速度过大。
  • Curriculum/ball_target_region/success_rate：课程学习用成功率；Hit/Cross/Continuous 的语义不同，解读时要结合任务。
